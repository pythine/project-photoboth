💞 Hubungkan Firebase (gratis)

  1. Buka console.firebase.google.com → Add project (paket Spark gratis).
  2. Build → Realtime Database → Create Database (lokasi Singapore). Buka tab Rules, tempel rules di bawah, lalu Publish.
  3. Project settings → Your apps → Web (</>), salin isi firebaseConfig dan tempel di kotak bawah.
  4. Upload file ini ke hosting HTTPS (Netlify Drop, GitHub Pages, atau Firebase Hosting). Kamera & mikrofon tidak jalan di HP lewat file:// atau http://.
  5. Klik Buat Ruang Baru → Salin Link → kirim ke pasangan. Link sudah membawa konfigurasi, jadi dia tidak perlu setting apa-apa.
