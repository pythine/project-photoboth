Kalkulator Gaji Karyawan

Tampilan dibuat dengan HTML, seluruh perhitungan dijalankan oleh mesin Java.

Input Data

Gaji Pokok (Array Gaji)

Persen Lembur (Array Lembur)

Slip Gaji

Isi data di sebelah kiri lalu tekan “Hitung Gaji”.

Frontend: HTML + CSS + JavaScript  |  Backend: Java (Array, IF, Operator)
